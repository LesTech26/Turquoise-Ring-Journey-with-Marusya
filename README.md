# 🎮 Путешествие по бирюзовому кольцу России

**Образовательное приложение для детей о культуре и традициях Орловской области**

## 📋 О проекте

Интерактивное веб-приложение для изучения 24 районов Орловской области через игры, викторины и знакомство с народными костюмами.

### ✨ Особенности:
- 🗺️ Интерактивная карта с 24 районами
- 🎭 Изучение народных костюмов каждого района
- 🎮 9 обучающих мини-игр
- 👧 3D-маскот "Маруся" (интерактивный персонаж)
- 🏆 Система достижений и прогресса

## 🎯 Для одногруппников

### Как интегрировать игры:

1. Игры находятся в `turquoise/games/`
2. Каждая игра — отдельный PHP файл
3. Все используют единый шаблон `templates/game-layout.php`
4. Для добавления в меню обнови `turquoise/game.php`

---

## 🤝 Командная разработка

### Git Workflow:

1. Каждый разработчик работает в своей ветке
2. Merge в `main` только через Pull Request
3. Перед началом: `git pull origin main`
