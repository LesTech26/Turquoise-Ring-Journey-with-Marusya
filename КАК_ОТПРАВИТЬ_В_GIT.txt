Ошибка: "Git не распознан"
→ Установи Git: https://git-scm.com/

Ошибка: "Branch already exists"
→ Ты уже создал ветку, просто переключись:
  git checkout feature/games-developer4

Ошибка: "Permission denied"
→ Настрой Git:
  git config --global user.name "Твоё Имя"
  git config --global user.email "твой@email.com"

Ошибка: "Conflict"
→ Спроси одногруппника или преподавателя
