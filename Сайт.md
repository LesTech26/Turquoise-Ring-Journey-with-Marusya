# Техническое задание на разработку веб-сайта
## «Путешествие по бирюзовому кольцу России»

---

## 1. Общие сведения

### 1.1. Наименование проекта
Веб-сайт **«Путешествие по бирюзовому кольцу России»**

### 1.2. Цель проекта
Создание интерактивного образовательного веб-сайта для детей и взрослых, направленного на изучение культуры, истории и традиционных народных костюмов районов Орловской области.

### 1.3. Целевая аудитория
- Дети 7–14 лет
- Школьники, изучающие краеведение
- Семьи, интересующиеся культурой Орловского региона
- Учителя начальных классов и истории
- Туристы и гости региона

### 1.4. Технологический стек
| Компонент | Технология |
|-----------|------------|
| Backend | PHP 7.4+ |
| Frontend | HTML5, CSS3, JavaScript (ES6+) |
| База данных | MySQL 5.7+ |
| CSS-препроцессор | SCSS (опционально) |
| JavaScript-библиотеки | Three.js (3D), Chart.js (статистика), GSAP (анимации) |
| Сборка | Webpack / Gulp (опционально) |
| Сервер | Apache / Nginx |

### 1.5. Требования к сайту
| Параметр | Значение |
|----------|----------|
| Адаптивность | Desktop + Mobile + Tablet |
| Кроссбраузерность | Chrome, Firefox, Safari, Edge |
| Скорость загрузки | < 3 секунд |
| SEO | Оптимизирован для поисковых систем |

## 2. Функциональные требования

### 2.1. Основные разделы сайта

#### 2.1.1. Главная страница
- Интерактивная карта Орловской области с районами (SVG)
- Блок с Марусей (анимированный персонаж, CSS/JS анимации)
- Последние добавленные районы
- Счётчик прогресса
- Кнопки быстрого доступа

#### 2.1.2. Страница района
URL: `/district/{slug}`

**Блок 1: Общая информация**
- Название района
- Герб района
- Краткое описание

**Блок 2: История района**
- Полное описание с адаптацией для детей
- Временная лента событий (горизонтальный скролл)
- Фотографии и иллюстрации (галерея)
- Интересные факты (аккордеон/карточки)

**Блок 3: Культурный наряд**
- Описание традиционного костюма
- Интерактивная 3D-модель с элементами (Three.js)
- Возможность переодевания (Drag & Drop)
- Инфографика с названиями элементов (кликабельные метки)

**Блок 4: Мини-игра**
- 5 вопросов по пройденному материалу
- Интерактивные элементы (перетаскивание, выбор ответов)
- Бонусные баллы
- Результат с наградой (анимация)

#### 2.1.3. Дополнительные страницы

| Страница | URL | Описание |
|----------|-----|----------|
| Игры | `/games` | Все мини-игры в одном месте |

## 5. Структура базы данных (MySQL)

### 5.1. Таблица `users`
```sql
CREATE TABLE users (
    id INT AUTO_INCREMENT PRIMARY KEY,
    username VARCHAR(50) NOT NULL,
    email VARCHAR(100) NOT NULL UNIQUE,
    password VARCHAR(255) NOT NULL,
    role ENUM('admin', 'editor', 'user') DEFAULT 'user',
    avatar VARCHAR(255) DEFAULT NULL,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    INDEX idx_email (email)
);
5.2. Таблица districts
sql
CREATE TABLE districts (
    id INT AUTO_INCREMENT PRIMARY KEY,
    name VARCHAR(100) NOT NULL,
    slug VARCHAR(100) NOT NULL UNIQUE,
    short_description TEXT,
    full_description TEXT,
    children_description TEXT,
    coat_of_arms VARCHAR(255),
    map_x INT,
    map_y INT,
    is_active BOOLEAN DEFAULT TRUE,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    INDEX idx_slug (slug),
    INDEX idx_active (is_active)
);
5.3. Таблица district_photos
sql
CREATE TABLE district_photos (
    id INT AUTO_INCREMENT PRIMARY KEY,
    district_id INT NOT NULL,
    image_path VARCHAR(255) NOT NULL,
    caption VARCHAR(200),
    sort_order INT DEFAULT 0,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    FOREIGN KEY (district_id) REFERENCES districts(id) ON DELETE CASCADE
);
5.4. Таблица timeline_events
sql
CREATE TABLE timeline_events (
    id INT AUTO_INCREMENT PRIMARY KEY,
    district_id INT NOT NULL,
    year VARCHAR(20) NOT NULL,
    title VARCHAR(200) NOT NULL,
    description TEXT,
    icon VARCHAR(50),
    sort_order INT DEFAULT 0,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    FOREIGN KEY (district_id) REFERENCES districts(id) ON DELETE CASCADE
);
5.5. Таблица costume_elements
sql
CREATE TABLE costume_elements (
    id INT AUTO_INCREMENT PRIMARY KEY,
    district_id INT NOT NULL,
    name VARCHAR(100) NOT NULL,
    description TEXT,
    image_path VARCHAR(255),
    model_path VARCHAR(255),
    category ENUM('head', 'torso', 'belt', 'legs', 'shoes', 'accessories') DEFAULT 'torso',
    sort_order INT DEFAULT 0,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    FOREIGN KEY (district_id) REFERENCES districts(id) ON DELETE CASCADE
);
5.6. Таблица quiz_questions
sql
CREATE TABLE quiz_questions (
    id INT AUTO_INCREMENT PRIMARY KEY,
    district_id INT NOT NULL,
    question TEXT NOT NULL,
    option_a VARCHAR(255) NOT NULL,
    option_b VARCHAR(255) NOT NULL,
    option_c VARCHAR(255) NOT NULL,
    option_d VARCHAR(255) NOT NULL,
    correct_answer VARCHAR(1) NOT NULL,
    difficulty ENUM('easy', 'medium', 'hard') DEFAULT 'medium',
    points INT DEFAULT 10,
    sort_order INT DEFAULT 0,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    FOREIGN KEY (district_id) REFERENCES districts(id) ON DELETE CASCADE
);
5.7. Таблица user_progress
sql
CREATE TABLE user_progress (
    id INT AUTO_INCREMENT PRIMARY KEY,
    user_id INT NOT NULL,
    district_id INT NOT NULL,
    is_completed BOOLEAN DEFAULT FALSE,
    quiz_score INT DEFAULT 0,
    collected_costume BOOLEAN DEFAULT FALSE,
    completed_at TIMESTAMP DEFAULT NULL,
    updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    FOREIGN KEY (user_id) REFERENCES users(id) ON DELETE CASCADE,
    FOREIGN KEY (district_id) REFERENCES districts(id) ON DELETE CASCADE,
    UNIQUE KEY (user_id, district_id)
);
5.8. Таблица user_achievements
sql
CREATE TABLE user_achievements (
    id INT AUTO_INCREMENT PRIMARY KEY,
    user_id INT NOT NULL,
    achievement_type VARCHAR(50) NOT NULL,
    achievement_value VARCHAR(100),
    earned_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    FOREIGN KEY (user_id) REFERENCES users(id) ON DELETE CASCADE
);

Работа 3D-маскота и переодевание

Сохранение прогресса пользователя

Работа админ-панели (CRUD)

Время загрузки < 3 секунд

Корректное отображение во всех браузерах

Полная адаптивность (Desktop, Tablet, Mobile)

Валидный HTML/CSS

Без ошибок в консоли

Единый стиль на всех страницах

Анимации плавные и соответствуют стилю
