# Техническое задание на разработку мобильного приложения
## «Путешествие по бирюзовому кольцу России»

---

## 1. Общие сведения

### 1.1. Наименование проекта
Мобильное приложение **«Путешествие по бирюзовому кольцу России»**

### 1.2. Цель проекта
Создание интерактивного образовательного приложения для детей, направленного на изучение культуры, истории и традиционных народных костюмов районов Орловской области.

### 1.3. Целевая аудитория
- Дети 7–14 лет
- Школьники, изучающие краеведение
- Семьи, интересующиеся культурой Орловского региона
- Учителя начальных классов и истории

### 1.4. Платформа
| Параметр | Значение |
|----------|----------|
| Операционная система | Android 8.0+ |
| Язык разработки | Java |
| Среда разработки | Android Studio |
| Минимальная версия SDK | API 26 (Android 8.0 Oreo) |
| Рекомендуемая версия SDK | API 33 (Android 13) |

## 2. Функциональные требования

### 2.1. Основные разделы приложения

#### 2.1.1. Карта путешествий
- Интерактивная карта Орловской области с отметками всех районов
- Каждый район — это отдельный уровень (занятие)
- Прогресс прохождения отображается на карте
- Анимированные переходы между районами

#### 2.1.2. Изучение района
Для каждого района реализуется следующий сценарий:

**Блок 1: История района**
- Текстовое описание с адаптацией для детей
- Исторические факты в виде временной ленты
- Фотографии и иллюстрации
- Голосовое озвучивание (синтез речи)

**Блок 2: Культурный наряд**
- Подробное описание традиционного костюма района
- Интерактивный 3D-показ элементов костюма
- Возможность приближать/вращать модель
- Инфографика с названиями элементов

**Блок 3: Мини-игра на усвоение**
- 3–5 вопросов по пройденному материалу
- Варианты ответов с картинками
- Бонусные баллы за правильные ответы

#### 2.1.3. Разделы приложения

| Раздел | Описание |
|--------|----------|
| **Карта** | Главный экран с картой области |
| **Маскот** | Интерактивный персонаж, игры, диалоги |
| **Творчество** | Раскраски, кроссворды |
| **Достижения** | Прогресс, награды, наклейки |
| **Медиатека** | Собранные материалы по всем районам |
| **Настройки** | Звук, язык, сброс прогресса |

---

### 2.2. Маскот-персонаж (3D интерактивный)

#### 2.2.1. Описание персонажа
| Параметр | Значение |
|----------|----------|
| Имя | **Маруся** |
| Стиль | 3D-мультяшный с элементами русского-народного стиля |
| Характер | Дружелюбная, любознательная, весёлая, заботливая |
| Возраст | 8–10 лет (по внешнему виду) |

**Анимации:**
- Приветствие (машет рукой, улыбается)
- Удивление (широко открывает глаза)
- Радость (хлопает в ладоши, подпрыгивает)
- Задумчивость (подпирает щёку рукой)
- Указующий жест (при объяснении)
- Танец (народный, задорный)
- Огорчение (опускает плечи)
- Кивок/отрицание головой

#### 2.2.2. Интерактивность маскота

**Диалоги**
- Озвучивание текста с использованием синтеза речи (TTS)
- Анимированные реплики (движение губ, мимика)
- Выбор вариантов ответа (взаимодействие с пользователем)
- Реакция на выбор ребёнка (похвала, поддержка)

**Переодевание**
- Drag & Drop элементы костюма на маскота
- 3D-рендеринг смены одежды в реальном времени
- Бонус за правильное сочетание элементов
- Возможность сохранять результат в «Галерею костюмов»

**Игры с маскотом**

| Игра | Описание | Механика |
|------|----------|----------|
| **«Угадай район»** | По описанию и картинкам выбрать район | Выбор из 3 вариантов |
| **«Собери костюм»** | Перетащить элементы на маскота | Drag & Drop |
| **«Правда/Неправда»** | Факты об Орловской области | Да/Нет |
| **«Кто это?»** | Узнай историческую личность по описанию | Выбор из 3 вариантов |
| **«Народные промыслы»** | Соотнеси ремесло и район | Сопоставление |

---

### 2.3. Мини-игры

#### 2.3.1. Кроссворды
- Сетка 5×5, тематические слова (районы, элементы костюмов, исторические личности)
- Подсказки (в том числе голосовые от Маруси)
- Анимация заполнения клеток
- Награда за полное решение

#### 2.3.2. Раскраски
- Чёрно-белые шаблоны (элементы костюмов, гербы районов)
- Палитра цветов (12 основных цветов)
- Инструменты: кисть, заливка, ластик, выбор цвета
- Сохранение готовой работы в галерею устройства

#### 2.3.3. Дополнительные мини-игры

| Игра | Описание | Механика |
|------|----------|----------|
| **«Пазл»** | Собрать картинку с нарядом района | Перетаскивание фрагментов |
| **«Мемори»** | Найди пару (элементы костюмов) | Открытие карточек |
| **«Викторина»** | 10 вопросов по всем районам | Выбор ответа |
| **«Найди отличие»** | Два варианта костюма, найти отличия | Сравнение изображений |
| **«Лабиринт»** | Проведи Марусю по историческому маршруту | Свайп |

---

### 2.4. Админ-панель

**Активация:** Нажатие на логотип приложения 5 раз подряд

**Функции:**
- Редактирование контента районов (текст, изображения, факты)
- Управление вопросами викторины
- Управление элементами костюмов
- Добавление новых районов
- Просмотр статистики пользователей
- Выгрузка/загрузка данных (экспорт в JSON, импорт)
- Сброс прогресса всех пользователей

## 5. Технические требования

### 5.1. Технологический стек

| Компонент | Технология |
|-----------|------------|
| Язык | Java |
| Архитектура | MVVM (ViewModel + LiveData) |
| База данных | Room (SQLite) |
| Сеть | Retrofit (опционально) |
| Изображения | Glide |
| 3D-движок | Unity (рекомендуется) / Sceneform |
| TTS | Google Text-to-Speech API |
| Аналитика | Firebase Analytics |

### 5.2. Структура базы данных (Room)

**Таблицы:**
- `users` — прогресс пользователя
- `districts` — районы (контент)
- `costumes` — элементы костюмов
- `games` — статистика игр
- `achievements` — достижения
- `questions` — вопросы викторины

### 5.3. Требования к производительности

| Параметр | Значение |
|----------|----------|
| Время запуска | < 3 секунд |
| FPS (3D-сцены) | > 50 fps |
| Размер приложения | < 200 MB |
| ОЗУ (фоновый режим) | < 256 MB |
| Автономная работа | Полная (без интернета) |

### 5.4. Требования к 3D-моделям

| Параметр | Значение |
|----------|----------|
| Формат | .glb (glTF) или .fbx |
| Стиль | Low-poly с качественными текстурами |
| Анимации | Скелетная (12+ анимаций) |
