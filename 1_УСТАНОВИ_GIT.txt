═══════════════════════════════════════════════════════════
  ШАГ 1: УСТАНОВКА GIT (5 минут)
═══════════════════════════════════════════════════════════

1. Открой эту ссылку в браузере:
   https://git-scm.com/download/win

2. Скачай установщик (Git-xxx-64-bit.exe)

3. Запусти установщик

4. Нажимай "Next" на всех экранах (настройки по умолчанию)

5. Нажми "Install"

6. После установки нажми "Finish"

7. Закрой и открой заново любые окна терминала

═══════════════════════════════════════════════════════════
  ПРОВЕРКА УСТАНОВКИ
═══════════════════════════════════════════════════════════

Открой новый терминал (CMD) и введи:
   git --version

Если увидишь "git version 2.xx.x" - всё готово!
